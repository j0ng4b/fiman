# Protótipos

As telas do sistema são desenhadas na ferramenta de design. Não há documento por
tela: o protótipo é a especificação visual, e o comportamento está nos
[requisitos](../requisitos.md) e nos [casos de uso](../casos-de-uso/README.md).

- **Ferramenta:** Figma
- **Arquivo editável:** <!-- URL em breve -->

## Convenção

- Cada tela tem um nome no arquivo de design (ex.: "Dashboard", "Novo
  lançamento"). É por esse nome que os casos de uso se referem a ela.
- Se uma tela mudar o comportamento do sistema, atualizar o requisito ou o caso
  de uso, não o protótipo apenas.
