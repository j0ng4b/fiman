# Casos de uso

Passo a passo de como o usuário realiza uma tarefa no sistema. Cada caso de uso
é escrito junto da fatia de código que o exige.

Nem todo requisito precisa de um caso de uso. Cadastros simples (contas,
categorias) ficam só nos [requisitos](../requisitos.md). Vale escrever um caso
de uso quando há fluxo com várias etapas, decisões ou exceções (por exemplo,
criar um parcelamento ou confirmar um lançamento).

Para criar um novo, copie [`template.md`](template.md). Nomeie o arquivo
`UC-xxx-verbo-objeto.md`.
